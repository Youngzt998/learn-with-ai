Blackwell B200 hardware hierarchy, mapped to CUDA C++ and PTX

Each panel zooms into the outlined block of the one above: package, die, GPC, SM and SMSP, down to the 32 threads of a single warp. Color marks the kind of hardware: solid blocks compute, striped blocks store, and thinner links carry more bandwidth. The cards on either side pair the most common CUDA C++ at each level with its PTX equivalent; their numbers match the round markers in the diagram.

Compute units (solid)

  • CUDA core (FP32 / INT32)
  • FP64 unit
  • SFU (ex2, sin, rsqrt, …)
  • Tensor Core (5th gen)

Memory (striped)

  • Register file
  • L1 data cache / shared memory
  • Tensor Memory (TMEM)
  • L2 cache
  • HBM3e DRAM
  • Instruction caches

Data movement, control and I/O

  • Data movers: LD/ST, TMA, copy engines
  • Scheduling: GigaThread engine, warp schedulers
  • Interfaces: NVLink, PCIe, C2C, NV-HBI, memory controllers
  • Off-chip peer, or a block drawn in another panel

Software abstractions

  • Thread block cluster
  • CTA (thread block)
  • Warp (32 threads)
  • Thread (one lane)

Line weight is bandwidth (thinner is faster)

  • Registers ↔ ALUs (≈450 TB/s chip-wide, estimate)
  • TMEM ↔ Tensor Core, tcgen05.ld
  • SMEM ↔ SMSP, warp shuffle (128 B/clk per SM)
  • SM ↔ SM (DSMEM, within a GPC)
  • SM ↔ L2 ≈21 TB/s; NV-HBI 10 TB/s
  • L2 ↔ HBM3e, 8 TB/s
  • NVLink 5: 1.8 TB/s bidirectional
  • NVLink-C2C: 900 GB/s bidirectional
  • PCIe Gen6 ×16: 256 GB/s bidirectional
  • Control / issue (not a data path)
  • Leader line to a code card

Software level ↔ hardware

  • Grid ↔ the whole GPU (2 dies, 8 GPCs, 148 SMs)
  • Cluster ↔ a group of SMs in one GPC
  • CTA ↔ one SM, which can host several CTAs
  • Warpgroup (4 warps) ↔ the 4 SMSPs
  • Warp ↔ one scheduler slot in an SMSP
  • Thread ↔ one lane: a register column plus an ALU lane

This diagram targets the data-center Blackwell B200 (sm_100a). Consumer Blackwell (RTX 50 series, sm_120) has no TMEM and does not support tcgen05 instructions.

Illustrative, not measured: the block placement inside each die, which SMs are fused off, and the kernel and cluster assignment are examples. FP64 ×16 and SFU ×4 per SMSP are inferred from published throughput; the LD/ST unit count is not labeled. The L2 bandwidth figure is a third-party measurement.

Sources: NVIDIA Technical Blog, “Inside NVIDIA Blackwell Ultra” (Aug 2025); Chips and Cheese, “Nvidia’s B200: Keeping the CUDA Juggernaut Rolling” (Dec 2025); arXiv 2512.02189 (B200 microbenchmarks); CCCL libcu++ cuda::ptx documentation and the PTX ISA.
